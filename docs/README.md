# RGB-D Depth Lab - Full Video

完整视频双版本离线页面，所有 HTML、脚本、目录数据和 85 个 MP4 均保存在当前文件夹，不连接远端服务器，也不需要启动本机 HTTP 服务。

一键打开：双击 `一键启动_离线页面.cmd`。

也可以直接双击 `index.html`。页面地址会是 `file:///.../index.html`。

可切换的两个版本：

- 深度处理对比：页面顶部选择“深度处理对比”。
- ACT 热力图对比：页面顶部选择“ACT 热力图对比”。

ACT 热力图页面已接入最新的批准 ROI 指标：19 次抓取、2,813 个有效执行腕 ROI。头部与执行腕作为主要结果，非执行腕仅保留为同步视觉对照；7 种真实深度处理方法按执行腕 ROI lift 排名，并同时显示以三相机全部注意力为分母、未对执行腕重新归一化的全局 ROI mass，以及配对置信区间、目标/背景注意力密度比、峰值命中率与动作 MAE 综合分析。默认对比为 LingBot-Depth v0.5 与原始对齐深度。

RGB、方法 A 和方法 B 均为 Head、Left Wrist、Right Wrist 三视角完整 MP4，共用页面底部的可拖动时间轴、逐帧按钮和播放速度控制。接触关键帧及黄色批准 ROI 可通过“查看接触关键帧”打开。

本机 HTTP 方式仍作为兼容备选：

```powershell
python serve_viewer.py --port 8767
```

媒体包括 5 个数据集、5 个完整 RGB 三相机视频、35 个完整深度三相机视频，以及 45 个完整无 Prompt ACT 热力图三相机视频。
