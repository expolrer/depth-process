训练约束

保持物理与时序一致

  • 亮度、对比度、饱和度、色相、锐度、RGB 高斯噪声和 Gamma 只改变 RGB，不能对 metric depth 套用同名光度运算。
  • RandomMask 与 RandomBorderCutout 在版本二复用相同空间掩码，深度对应位置写入无效值 0。
  • 增强不改变像素坐标，因此相机内参、关节状态、动作标签和 prompt 均保持不变。
  • 一个观测时间窗应复用变换类型和空间掩码；高斯噪声可按帧变化，避免视频闪烁式的随机策略切换。
